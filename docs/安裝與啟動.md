# 安裝與啟動（新電腦）

> 適用：全新 Windows 電腦（Windows 10/11）。整個流程約 1～10 分鐘。

## 最快速：可攜版（免安裝 Node.js）

1. 下載 `it-asset-manager-web-portable-vX.Y.Z.zip`（約 44 MB，內含 Node.js 與相依套件）
2. 解壓縮到固定資料夾，例如 `D:\IT資產管理系統`
3. 雙擊 **`start.bat`** → 自動開啟 <http://localhost:3010>

- ✅ 不用安裝 Node.js、不用 `npm install`、不用網路
- 第一次啟動會在該資料夾自動建立 `data\asset_data.db`（預設帳號 `admin` / `5508888`）
- 完整說明在解壓後的 `安裝與啟動.txt`
- 以下一～三節為「自行安裝 Node.js」的方式（開發或要改程式時使用）

## 一、安裝 Node.js（只需一次）

1. 開啟 https://nodejs.org/ → 下載 **LTS** 版本（建議 20 或 22 以上，64-bit Windows Installer）
2. 安裝時一路「Next」即可（**不要**取消 "Add to PATH"）
3. 安裝完成後，開啟「命令提示字元」輸入：

```powershell
node --version
npm --version
```

看到版本號（例如 `v22.x.x`）就代表成功。若顯示找不到指令，請重新開機再試。

## 二、取得 Web 版程式

**方法 A：下載 Release ZIP（最簡單）**

1. 開啟 https://github.com/Kevin7563/it-asset-manager-web/releases
2. 最新版本 → 下載 `it-asset-manager-web-vX.Y.Z.zip`
3. 解壓縮到固定位置，例如 `D:\it-asset-manager-web`
4. ⚠️ 不要放在「桌面」或「下載」資料夾（避免被清理），也不要放在需要系統管理員權限的 `C:\Program Files`

**方法 B：git clone（要更新程式碼時較方便）**

```powershell
git clone https://github.com/Kevin7563/it-asset-manager-web.git D:\it-asset-manager-web
```

## 三、啟動

**方法 A：雙擊 `start.bat`（推薦）**

- 第一次會自動執行 `npm install`（需網路），完成後自動開啟瀏覽器
- 之後每次雙擊就會啟動，關閉黑色視窗即停止服務

**方法 B：手動指令**

```powershell
cd D:\it-asset-manager-web
npm install
npm start          # 或 npm run web（兩者相同）
```

瀏覽器開啟 http://localhost:3010

- 預設帳號：`admin` / `5508888`（全功能）
- 預設一般帳號：`User` / `1234`（一般查詢與報表匯出）
- 🔒 第一次登入後請立刻到「🔒 修改我的密碼」更換 `admin` 密碼，並到「👥 帳號管理」建立個人帳號

## 四、第一次啟動會自動建立

```
D:\it-asset-manager-web\data\asset_data.db      ← 資料庫（含預設帳號與欄位選項）
D:\it-asset-manager-web\data\vendor_files\      ← 廠商附件
D:\it-asset-manager-web\data\backups\           ← 備份
```

## 五、讓同一區網的其他電腦／手機連線

1. 查伺服器 IP：

```powershell
ipconfig | findstr IPv4
```

2. 其他裝置開啟 `http://<伺服器IP>:3010`（例如 `http://192.168.1.50:3010`）
3. 若連不上，到「Windows Defender 防火牆 → 允許應用程式通過防火牆」允許 **Node.js JavaScript Runtime**（私人網路），或直接關閉該網路類型的防火牆測試
4. 伺服器電腦請設定**固定 IP**，避免 IP 變動造成連不上

## 六、搬移既有資料（從舊電腦）

把舊電腦的 `data\` 整個資料夾複製到新電腦同一位置即可（含 `asset_data.db`、`vendor_files`、`imported_files`）。
**先停止兩邊的服務**再複製，避免資料庫鎖定。

若之前是單機版（Electron），用法不同：
- 單機版備份 `.db`／`.zip` → 登入新 Web 版 → 「📥 匯入／備份 → 📥 匯入單機版備份」
- 附件路徑不正確時再用「🔧 附件路徑修復」

## 七、更新版本

Web 版內建線上更新：

1. 以「全功能」帳號登入 → 「系統管理」→「🔄 版本與更新」
2. **🔄 檢查更新** → **⬇️ 下載更新檔** → **✅ 套用並重新啟動**
3. 資料庫、附件、`config.json` 不會被更動；更新前會自動備份程式檔到 `data\backups\`

> 若是在下載的 ZIP 裡直接更新，也可以重新下載新 ZIP 解壓覆蓋程式檔（保留 `data\` 與 `config.json`）。

## 八、常見問題

| 症狀 | 處理方式 |
| --- | --- |
| 雙擊 start.bat 一閃就消失 | 對 `start.bat` 按右鍵 →「以系統管理員身分執行」，或先開啟「命令提示字元」再手動 `npm start` 看錯誤 |
| `npm install` 卡住／失敗 | 確認網路；公司網路可能需要 proxy：`npm config set proxy http://proxy:port`；或改用其他網路 |
| 出現 `sqlite3` 相關錯誤 | 安裝 Node.js LTS（20/22）→ 刪除 `node_modules` → 重新執行 `start.bat` |
| 連接埠 3010 被占用 | 建立 `config.json` 設 `{"port": 3011}`，或關閉占用程式（`netstat -ano | findstr :3010`） |
| 忘記 admin 密碼 | 用另一個「全功能」帳號登入重設；若沒有，停止服務後備份 `data\asset_data.db`，使用 `data\backups\` 內較早的備份還原 |
| 想每天自動啟動 | 參考 `docs\安裝與啟動.md` 的「開機自動啟動（進階）」 |
| 匯入後「維運備註說明」變成跟「資產規格/備註」一樣 | 舊版匯入的欄位誤配（v1.1.0 已修正）。到「📥 匯入／備份 → 🧰 資料修復」勾「清除重複的維運備註」→ 預覽 → 執行 |
| 資產編號中間是匯入當天的日期（不是採購日期） | v1.1.0 起新資料會用採購日期；既有資料請到「🧰 資料修復」勾「重新產生資產編號」→ 預覽 → 執行 |

## 九、開機自動啟動（進階，伺服器建議）

**方式 A：工作排程器**

1. 「工作排程器」→ 建立基本工作 → 觸發程序「電腦啟動時」
2. 動作「啟動程式」：
   - 程式：`C:\Program Files\nodejs\node.exe`
   - 引數：`server.js`
   - 起始於：`D:\it-asset-manager-web`
3. 勾選「不論使用者是否登入都執行」

**方式 B：NSSM（以 Windows 服務執行）**

```powershell
nssm install ITAssetWeb "C:\Program Files\nodejs\node.exe" "D:\it-asset-manager-web\server.js"
nssm set ITAssetWeb AppDirectory "D:\it-asset-manager-web"
nssm set ITAssetWeb AppEnvironmentExtra WEB_PORT=3010
nssm start ITAssetWeb
```

> 以服務執行時，`data\` 會建立在 `D:\it-asset-manager-web\data`（可用 `WEB_DB` 指定其他位置）。
